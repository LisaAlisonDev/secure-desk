# 🔐 SecureDesk

**SecureDesk** est une plateforme web de gestion d'incidents informatiques développée avec **Laravel** et **Vue.js**.

L'objectif du projet est de concevoir une application réaliste permettant aux utilisateurs de déclarer des incidents, aux techniciens de les traiter et aux administrateurs de superviser l'ensemble de l'activité.

Le projet met particulièrement l'accent sur la **sécurité applicative**, la gestion fine des permissions et la traçabilité des actions.

## 🚀 Fonctionnalités

* 🔑 Authentification et gestion des utilisateurs
* 🎫 Création et suivi des tickets
* 👥 Gestion des rôles et permissions
* 📊 Tableau de bord
* 🔎 Recherche, filtrage et pagination
* 💬 Commentaires sur les incidents
* 📎 Gestion des pièces jointes
* 🔔 Notifications
* 📝 Journal d'audit des actions
* 🔐 Classification et niveau de criticité des incidents
* 🌐 API REST
* 🛡️ Mesures de sécurité applicative
* 🧪 Tests automatisés
* 🐳 Conteneurisation avec Docker

## 🎯 Objectif du projet

Ce projet a été conçu comme un **projet de portfolio orienté développement Full-Stack et cybersécurité**, avec l'objectif de reproduire les problématiques rencontrées dans une application professionnelle réelle.

Il permet notamment de mettre en pratique la conception d'une API, la gestion des utilisateurs et des permissions, la sécurisation d'une application web, la persistance des données, les tests et le déploiement avec Docker.
